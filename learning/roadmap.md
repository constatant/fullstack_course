# План обучения

## Цель

Научиться самостоятельно написать React-интерфейс для своего проекта и подключить его к тестовому серверу через CRUD: Create, Read, Update и Delete. План строится вокруг практики; готовое приложение за ученика не создаётся.

Ученик знает Python и базовый синтаксис JavaScript. Переменные, циклы и функции повторяем только там, где проявятся важные отличия JavaScript.

## Маршрут

| № | Тема | Результат занятия |
|---|---|---|
| 1 | Асинхронность JavaScript: Event Loop, Promise, async/await | Объясняешь порядок выполнения и пишешь простые асинхронные функции |
| 2 | HTTP, REST API, JSON и fetch | Читаешь запросы и ответы, самостоятельно отправляешь GET-запрос |
| 3 | React, JSX и компоненты | Создаёшь минимальную страницу и разбиваешь её на компоненты |
| 4 | Props, списки и условный рендеринг | Передаёшь данные компонентам и отображаешь коллекции |
| 5 | useState и события | Самостоятельно добавляешь интерактивное состояние |
| 6 | Формы и управляемый ввод | Собираешь и проверяешь данные формы для создания и редактирования |
| 7 | useEffect и загрузка данных | Загружаешь данные при открытии страницы, показываешь загрузку и ошибки |
| 8 | CRUD-запросы: POST, PATCH/PUT, DELETE | Поэтапно реализуешь все операции в своём приложении |
| 9 | Структура, CSS и итоговая проверка | Приводишь свой интерфейс к дизайну и проверяешь основные сценарии |

## Как устроено занятие

1. Короткое объяснение одной темы.
2. Небольшой пример, который разбирается вместе, а не копируется вслепую.
3. Упражнение, которое ученик сначала решает самостоятельно.
4. Проверка ответа и подсказки по необходимости.
5. Небольшой шаг в сторону собственного проекта, когда для него уже есть нужные знания.
6. Краткая запись результата в progress.md, concepts.md и mistakes.md по необходимости.

Темп можно менять. Если тема не усвоена, её нужно закрепить дополнительным упражнением, а не формально переходить к следующему пункту.

## Что пока не входит в маршрут

Сначала нужны только знания, необходимые для текущего React-интерфейса. Redux, Next.js, сложная оптимизация и продвинутые архитектурные паттерны можно изучать позже, если они понадобятся проекту.
