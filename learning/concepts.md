## JavaScript

- Ученик сообщил, что знает базовый синтаксис JavaScript.
- Синхронные инструкции выполняются последовательно в текущем стеке вызовов.
- Вызов setTimeout() планирует callback как задачу и не блокирует синхронное продолжение программы.
- Promise.then() ставит callback в очередь микрозадач.
- После завершения синхронного кода Event Loop обрабатывает микрозадачи прежде, чем перейти к следующей задаче, например callback setTimeout().
- Для учебного примера с синхронными A, C, E, Promise-буквой D и setTimeout-буквой B правильный порядок: ACEDB.
