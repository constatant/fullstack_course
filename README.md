# Fullstack Course — учебный маршрут

Этот репозиторий помогает постепенно освоить JavaScript и React и самостоятельно подготовить frontend для зачётного проекта с CRUD.

## Как учиться

1. Открывай отдельный чат для каждого занятия. Перед началом передавай ему инструкцию из [learning/chat-instructions.md](learning/chat-instructions.md).
2. В начале занятия сверяйся с [планом](learning/roadmap.md), [прогрессом](learning/progress.md), [понятиями](learning/concepts.md) и [заметками об ошибках](learning/mistakes.md).
3. Сначала решай упражнения сам. Преподаватель объясняет тему и даёт подсказки, но не пишет за тебя готовое решение.
4. После занятия обновляй учебные заметки коротким итогом: что понял, что сделал самостоятельно, что повторить и какой следующий шаг.
5. Когда основа будет освоена, применяй её в своём проекте. Реализация CRUD остаётся твоей самостоятельной работой.

## Принцип курса

Сначала понимание, затем самостоятельная попытка, после этого разбор и обратная связь. Цель — не скопировать готовый CRUD, а научиться спроектировать и написать его самому.
